# Archic home — commercial direction 2026.4

Date: 2026-08-29  
Status: implementation contract  
Parent standard: `archic-design-system-1.0.0`

## Outcome

The home must explain in the first viewport that Archic builds more than websites: premium websites, web apps and custom web software that improve sales and operations. The existing Presence → Control → Business product system remains the signature proof.

## First-viewport copy lock

Spanish:

- Kicker: `ARCHIC / WEB · APPS · SOFTWARE`
- H1: `Más que una web. / Un sistema para crecer.`
- Lead: `Diseñamos y desarrollamos webs, web apps y software web a medida para negocios que necesitan vender mejor, operar con menos fricción y crecer sin depender de herramientas que no encajan.`
- Primary CTA: `Solicitar diagnóstico`
- Secondary CTA: `Ver proyectos`
- Friction reducer: `Diagnóstico inicial sin coste · Respuesta en 24–48 h laborables.`
- Capability rail: `Webs que convierten · Web apps a medida · Software web · Automatización`

English:

- Kicker: `ARCHIC / WEB · APPS · SOFTWARE`
- H1: `More than a website. / A system built to grow.`
- Lead: `We design and build websites, web apps and custom web software for businesses that need to sell better, operate with less friction and grow beyond tools that no longer fit.`
- Primary CTA: `Request a diagnosis`
- Secondary CTA: `View projects`
- Friction reducer: `No-cost initial diagnosis · Reply within 1–2 business days.`
- Capability rail: `Websites that convert · Custom web apps · Web software · Automation`

No additional hero badges, floating cards, gradients, glows, decorative imagery or unsupported metrics are allowed.

## Section continuity

1. Hero states the commercial promise and shows an operable product proof.
2. Work demonstrates public and private layers through clearly labelled concept builds.
3. System explains Presence, Control and Business as one scalable architecture.
4. Method and Quality Standard establish delivery confidence.
5. Investment provides entry points without forcing generic packages.
6. Diagnosis reduces scope uncertainty and leads to contact.

## Visual rules

- Preserve canonical Archic black `#0A0A0B`, gold `#C9A56A` and mineral paper surfaces.
- Preserve square controls, rule-based geometry, grotesk + mono typography and Type + Data direction.
- The new H1 should reduce line count and increase breathing room without reducing its first-viewport dominance.
- The CTA note must be subordinate, readable and never compete with the primary action.
- On mobile, CTA controls stack cleanly and the proof remains directly below the promise.

## Conversion integrity

- No client, award, outcome or scale claim is added.
- Demo metrics remain visibly marked as fictional.
- “24–48 h” applies to response time, not project delivery or diagnosis completion.
- The secondary CTA points to project evidence, not another explanation block.
