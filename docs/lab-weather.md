# Archic Lab / Weather — Implementation status

**Status:** experimental GitHub branch; not published to archic.es yet.

## Working slice
- Bilingual routes /lab/ and /lab/weather/, built alongside Archic's existing Vite multi-page site.
- A mobile-first forecast with six global presets, explicit latitude/longitude input and optional device geolocation.
- Real MET Norway location forecasts via the same-origin Vercel endpoint /api/lab/weather?lat=37.541&lon=-5.083.
- Rainfall totals over the next 6 and 24 hourly periods when complete; otherwise the UI displays unavailable. MET values are in mm, equivalent to litres per square metre.
- Model-based apparent temperature estimate, humidity, wind, gusts, dew point, cloud fraction, fog fraction, pressure and clear-sky UV when available.
- Source timestamp, UTC hour labels, source credit, errors, loading state and honest limitations. Simple and Detail controls change actual rendering.
- Static entrypoints generated by scripts/generate-lab-pages.ts rather than edited by hand.

## Not implemented — DO NOT fake
- Real-time station observations. MET Norway's near-current value is a model forecast, not a measured temperature.
- Official alert polygons and future warning probabilities.
- Radar, detected lightning and geospatial layers.
- Geocoded place-name search. The global MVP supports coordinates and predefined cities; public Nominatim must not be used for client-side autocomplete.
- Long-range ensembles, pollen, air quality, historical extremes and multivariate model comparison.
- Local time zone for arbitrary coordinates: hourly table labels are UTC.
- Global rain probabilities often absent; show unavailable rather than invent values.

## Provider usage and reliability
MET Norway permits commercial reuse with credit under CC BY. For backend requests, identify Archic with a descriptive User-Agent, respect upstream cache headers and avoid repeated load. The weather endpoint rounds coordinates to 0.001 degrees and includes an explicit fetch timeout. Provider outages return non-cacheable errors and never fabricated data. Before broad production use, add globally coordinated rate limits and abuse monitoring, then test Vercel cache behavior with real traffic.

Do not call Open-Meteo's non-commercial API from Archic's public promotional product without an appropriate agreement.

## Release gate
1. npm ci
2. npm run build
3. npm run quality:gate
4. Verify generated dist/lab/index.html, dist/lab/weather/index.html and English equivalents.
5. Test API handler on Vercel: invalid coordinates return 400; valid coordinates return MET points; no arbitrary upstream host.
6. Render desktop/mobile (320, 390, 768, 1440px), keyboard and reduced motion. Test nonzero, zero, unavailable rain and missing probabilities.
7. Verify metadata, language switching, hreflang and navigation without regressions on the existing marketing site.
8. Confirm MET Norway terms, source attribution and cache expiration before merging.
