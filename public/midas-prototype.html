Observation 1

The Context Rot problem

We found that giving an agent more context makes it perform worse. In our LoCoMo experiments, increasing the Midas budget from 512 to 1024 tokens raised recall but dropped correctness from 0.38 to 0.30 — the extra tokens introduced distractors that diluted the answer.

"Context rot is the hidden tax on long-horizon agents. More isn't better. Better is better."
— Internal evaluation, LoCoMo budget sensitivity study

Current memory systems (Mem0, Zep, Letta) rely on LLM-based synthesis that consumes tokens at ingest and query. Worse, when they expand the budget they include low-value turns that confuse the model. Midas was designed to solve this: selective retrieval beats total recall.

Architecture

How Midas works

Three layers of retrieval, each solving a different failure mode:

Layer 1
Semantic retrieval (bge-base)

Embeds queries and memory chunks into a shared vector space. Surfaces candidates by cosine similarity — the foundation of selective recall.

Layer 2
Neighbor window

Expands each hit by ±N turns around it. Reasoning: evidence spans multiple turns; isolated chunks lose the thread. This was the single largest correctness gain (+0.08).

Layer 3
Cross-encoder rerank

Precision filter. A pairwise relevance model scores each candidate turn against the query. Only the top-k survive into the budget. This added another +0.05 recall.

Zero-deps core
$ pip install midas

Pure Python. HashingEmbedder for offline dev. LocalEmbedder (fastembed/ONNX) for production. OpenAIEmbedder optional. SQLite store incoming.

Implementation

API surface

Three operations. Zero dependencies. Reproducible results.

# Midas — agentic memory in five lines
from midas import Memory

memory = Memory()

# Remember a turn
memory.remember("user", "Can you refactor the auth module?")

# Build context for a new query (budget-controlled)
ctx = memory.build_context("Check the auth PR", budget=512)

# ctx is a sorted list of turns, ready for your agent's prompt
response = agent.generate(ctx + "...")

The eval harness is not an afterthought — it ships with the SDK. Run uv run python -m eval.runner after every change. It is the regression net.

What happens when you give Midas more context?

At 1024 tokens, Midas recall rises to 0.86 but correctness drops to 0.30 — context rot. Memo self-limits to dense synthesized facts (~587 tok) and improves with headroom. Midas's design point is a tight budget where it wins on both correctness and efficiency.
