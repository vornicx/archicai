Arquitectura

Las tres columnas de Archic

Measure.

No optimizamos a ciegas. Cada cambio estructural en el SDK de memoria se mide bajo un arnés de pruebas con tolerancia cero a las alucinaciones de contexto.

Remember.

Construimos capas de abstracción para que los agentes retengan planes abstractos e hilos de ejecución durante ejecuciones complejas de largo horizonte.

Act.

Una memoria sin utilidad es ruido. Midas transforma la retención de datos históricos en llamadas a herramientas precisas y deterministas para el agente.

Developer experience

Integración limpia en menos de diez líneas

Diseñado para integrarse en arquitecturas de agentes existentes sin reescribir la lógica de orquestación principal. Midas actúa como una capa de memoria desacoplada de alta fidelidad. 

import { MidasMemory } from "@archic/midas";

// Inicialización con evaluación determinista activa
const memory = new MidasMemory({
  evalHarness: true,
  horizon: "7d"
});

await memory.commit(agentState);
const context = await memory.recall(query);
