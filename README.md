# archicai

Marketing site for [archic.es](https://archic.es) — the Archic ecosystem vision, stack overview, and links to code.

**Documentation** (protocol, ecosystem law, build plan) lives in [github.com/vornicx/archic](https://github.com/vornicx/archic).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

GitHub Actions publishes `dist/` to GitHub Pages on push to `main`. Configure the custom domain `archic.es` in the repository Pages settings if needed.
